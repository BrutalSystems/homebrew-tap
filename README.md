# BrutalSystems Homebrew tap

```sh
brew tap brutalsystems/tap
brew install --cask baobar
```

## Casks

- **[baobar](https://github.com/BrutalSystems/baobar)** — menu bar / system tray
  indicator for [OpenBao](https://openbao.org): shows whether you are signed in
  and how long your token has left.

Casks in this repository are generated by
[GoReleaser](https://goreleaser.com) on release. Edit them in the source
repository, not here.
